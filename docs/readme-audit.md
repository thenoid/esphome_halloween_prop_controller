# README hardware and code audit — 2026-10-25

The README was reviewed against the current private controller source, the public YAML after ESPHome package resolution, the maintainer's power/trigger corrections and existing wiring notes, and primary LILYGO/ESPHome references. This is a documentation and source audit, not a physical inspection or a readback of firmware/settings from installed boards.

## Scope and limits

The private/public source comparison found only the documented release adaptations: generic names/labels, the validated minimum ESPHome version, and disabling uploads in the normal web UI. This audit changes documentation only; relay polarity, GPIOs and sequence execution are unchanged.

Existing contact/choreography regressions, native protocol/limiter tests and C++ generation for all five entry points were rerun. The original release's full three-controller firmware builds remain recorded in [release-verification.md](release-verification.md); no additional full build is necessary for these documentation edits.

The records establish configured connections and the maintainer-confirmed trigger/power arrangement. They cannot establish present cable continuity, actual installed firmware, restored UI values, the fog remote's voltage/current, a particular prop's required hold time, or relay contact condition. The README therefore asks users to verify those items on their own hardware. Existing optional fan wiring notes do not install an automatic fan routine in these YAMLs or establish a motor switching rating for the onboard relays.
